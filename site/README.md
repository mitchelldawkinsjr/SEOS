# SEOS public explainer

Static interactive site for GitHub Pages.

- Live: https://mitchelldawkinsjr.github.io/SEOS/
- Source: `index.html`, `styles.css`, `app.js`
- Deploy: [`.github/workflows/pages.yml`](../.github/workflows/pages.yml) on push to `main` when `site/` changes

No build step — open `index.html` locally or wait for Pages after merge.
